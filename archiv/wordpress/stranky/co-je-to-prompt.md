# Co je to prompt

				
				
				
				
					Prompt je jednoduše vstupní text nebo zadání, které dáte chatbotovi (nebo jiné aplikaci, která generuje obsah), aby něco vytvořil. Je to něco jako otázka nebo instrukce, kterou mu zadáte, aby pro vás něco napsal nebo vytvořil.

				
				
				
				
					

### Konkrétní příklad

				
				
				
				
					Například když zadáte prompt „Napiš příběh o drakovi a princezně“, model použije tento vstup k vytvoření příběhu na toto téma. Prompt může být velmi jednoduchý, třeba jen jedním slovem, nebo složitější, pokud chcete konkrétnější výsledek.

				
				
				
				
					Čím jasněji a konkrétněji svůj prompt napíšete, tím lépe chatbot pochopí, co od něj chcete, a poskytne odpověď, která více odpovídá vašim představám.
